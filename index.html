알파값을 4단위로 반올림해 최하위 2비트를 지웁니다. 완전 불투명(255)·완전 투명(0)은 그대로이고, 반투명 가장자리는 최대 2단계만 바뀝니다. 완전 투명 픽셀 뒤에 숨은 색상값도 비웁니다.

    도움말

    무엇을 지우나요?

    • 일반 메타데이터 — PNG 텍스트 청크(NovelAI의 Comment·Description·Software 등), EXIF, XMP, 색 프로필, 주석, C2PA까지. 그림을 그리는 데 꼭 필요한 조각만 남기고 나머지는 모두 버립니다.
    • 스텔스 메타데이터 — NovelAI가 알파 채널 최하위 비트에 숨겨 두는 생성 정보(stealth_pngcomp)와 RGB 최하위 비트 방식(stealth_rgbinfo).

    “검증 완료”는 무엇을 확인한 건가요?

    변환이 끝나면 결과 파일을 다시 열어서 아래를 모두 확인한 뒤에만 표시합니다. 하나라도 실패하면 내려받기를 막습니다.

    • 파일 안에 그림 데이터 조각만 남았는지 (PNG: IHDR·IDAT·IEND / WebP: VP8 / JPEG: 그림 세그먼트와 JFIF 머리말)
    • 파일 전체에 NovelAI·prompt·Software·XMP·EXIF 같은 낱말이 없는지
    • NovelAI 판독기와 같은 순서로 알파·RGB 최하위 비트를 읽어 스텔스 서명이 없는지
    • 투명 모드: 출력 픽셀이 정리한 픽셀과 완전히 같은지, 불투명(255) 픽셀이 그대로인지

    직접 한 번 더 확인하기

    처음 쓸 때는 결과 파일을 novelai.net/inspect에 넣어 생성 정보가 뜨지 않는지 눈으로 확인해 보세요. (이 페이지는 그 사이트에 아무것도 보내지 않습니다)

    모드 고르기

    • 배경 있는 일러스트 → 일반 이미지. 용량이 가장 작습니다.
    • 캐릭터만 오려낸 스티커형 → 투명 이미지. 일반 모드로 바꾸면 투명한 곳이 흰색/검은색으로 채워집니다.

    휴대폰에서

    • 아이폰은 하나씩 받으면 파일 앱의 다운로드 폴더에 저장됩니다. 공유 버튼으로 사진 앱에 바로 저장할 수도 있습니다.
    • 안드로이드 크롬: 메뉴(⋮) → 앱 설치 / 아이폰 사파리: 공유 → 홈 화면에 추가. 한 번 열어 두면 인터넷 없이도 열립니다.
    • 한 번에 너무 많이 넣으면 휴대폰 메모리가 부족할 수 있습니다. 수십 장 단위로 나눠 주세요.
